# Hash Table

## Core idea

A hash table stores key-value pairs and uses a **hash function** to map keys to indices, allowing fast insertion, lookup, and deletion on average.

In DSA problems, hash tables help us remember previously seen elements, count frequencies, check membership, and establish relationships between values without repeatedly scanning an array.

## When to use it

- **Recognition patterns**
  - Finding duplicates or checking whether an element exists.
  - Counting the frequency of elements or characters.
  - Finding pairs or complements, such as Two Sum.
  - Grouping elements by a common property, such as anagrams.
  - Tracking previously seen elements or their indices.
  - Comparing two arrays or strings using frequency counts.
  - Storing mappings between elements, indices, or states.

- **Constraints that suggest this technique**
  - A brute-force solution uses nested loops to search for matching elements.
  - Repeated membership checks or frequency calculations are required.
  - The problem asks for an answer in one pass or near-linear time.
  - Elements can be used as keys in a dictionary or set.
  - Extra space is acceptable to reduce time complexity.

## Common patterns

- **Frequency counting:** Count occurrences using a dictionary.
- **Membership checking:** Use a set to check whether an element exists.
- **Complement lookup:** Store previously seen values and search for the required complement.
- **Index mapping:** Map each element to its index or another relevant position.
- **Grouping:** Map a common key to a list of related elements.
- **Duplicate detection:** Check whether an element has appeared before.
- **Prefix sum + hash table:** Track prefix sums and their frequencies or indices.
- **Frequency comparison:** Compare character or element counts between collections.
- **Last-seen index:** Store the most recent position of an element.
- **Counting subarrays:** Use prefix sums and a frequency map to count valid subarrays.

## Python template

```python
# Frequency counting
freq = {}

for x in nums:
    freq[x] = freq.get(x, 0) + 1


# Membership checking / duplicate detection
seen = set()

for x in nums:
    if x in seen:
        # Duplicate found
        pass
    seen.add(x)


# Complement lookup (Two Sum pattern)

for i, x in enumerate(nums):

    if complement in seen:
        # Found the required pair
        return [seen[complement], i]

    seen[x] = i


# Prefix sum + frequency map
prefix_sum = 0
freq = {0: 1}
count = 0

for x in nums:
    prefix_sum += x

    # Example: count subarrays with sum == k
    count += freq.get(prefix_sum - k, 0)

    freq[prefix_sum] = freq.get(prefix_sum, 0) + 1
```

## Complexity

- **Time:**
  - Lookup: O(1) average
  - Insertion: O(1) average
  - Deletion: O(1) average
  - Building a hash table with n elements: O(n) average
  - Worst-case operations can take O(n) due to hash collisions.

- **Space:**
  - O(n) in the worst case when storing n distinct elements.
  - O(1) auxiliary space when the number of stored keys is bounded by a constant.
